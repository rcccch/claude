# claude – Webagentur-Setup für Claude Code

- `setup-agentur.sh` – installiert Plugins, Skills, Context7 und CLI-Tools (`bash setup-agentur.sh`)
- `SETUP-BERICHT.md` – was installiert ist, warum, und was noch zu tun ist

- `reichkraft/` – Projektordner, Phase 1: Briefing

Jedes Kundenprojekt bekommt einen eigenen Unterordner.
